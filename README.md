# Hospital-Cost-Optimization-using-Activity-Based-Costing-ABC-
Problem Statement
Hospitals often struggle with unclear cost structures, leading to inefficient resource allocation and rising operational costs.

This project aims to identify:

Which hospital services are most expensive
What drives these costs
Where efficiency improvements can be made
Objective
To apply Activity-Based Costing (ABC) to accurately allocate costs across hospital services and uncover actionable insights for cost optimization.

Approach
1. Cost Structure Breakdown
Total hospital cost: ₹13.9 Cr

Cost components analyzed:

Doctor Salaries
Nursing Salaries
Diagnostic Equipment
Administrative Overheads
Facility Operations
Consumables
2. Activity Segmentation
Hospital services were divided into:

Outpatient Consultations
Diagnostic Imaging
Inpatient Admissions
Each activity was mapped with specific cost drivers:

Consultations → volume-driven
Diagnostics → machine usage
Inpatient → patient stay duration
3. Cost Allocation (ABC Model)
Costs were distributed based on actual resource usage instead of equal allocation.

👉 Result:

Outpatient: ₹3.80 Cr
Diagnostic: ₹4.30 Cr
Inpatient: ₹5.80 Cr
Key Findings
1. Inpatient Services Drive Maximum Cost
Contribute 42% of total cost
Highest cost per unit: ₹9,667
👉 Driven by:

High nursing time (70%)
Facility usage
Longer patient stays
2. Major Cost Drivers Identified
Doctor + Nursing + Admin = ~72% of total cost
Equipment cost dominates diagnostics
Admin overhead heavily impacts outpatient
3. Cost Efficiency Insights
Outpatient is lowest cost (₹633 per visit)
Inpatient is ~15x more expensive
Diagnostic sits in mid-range
Facility-Level Analysis
Facility	Efficiency	Insight
A	Low	Underutilized (60% occupancy)
B	Highest	Optimal utilization (sweet spot)
C	Moderate	Overloaded → higher marginal cost
Strategic Insights
Economies of scale exist up to optimal capacity
Beyond that → diseconomies of scale
Higher case complexity → higher cost
Occupancy has an inverted U-shaped relationship with efficiency
Recommendations
Operational
Reduce inpatient stay duration
Balance nurse workload
Improve bed utilization
Process
Automate outpatient workflows
Standardize treatment protocols
Financial
Focus cost control on staffing & admin
Implement differential pricing for services
Impact
If implemented, this model can:

Improve cost transparency
Enable better pricing strategies
Optimize hospital resource allocation
Reduce operational inefficiencies
